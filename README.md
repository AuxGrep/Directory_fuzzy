# Directory_fuzzy
discover hidden or sensitive directories and files on web servers

![directory_fuzzy](https://github.com/user-attachments/assets/106d0661-d391-470a-808a-793b43bbd68b)

# Feature
1. ✅ Cross-Platform Support (Windows, Linux, macOS)
2. 🌐 Wordlist Flexibility: Use local files or fetch wordlists from remote URLs
   
# Setup
1. git clone https://github.com/AuxGrep/Directory_fuzzy
2. pip3 install -r requirement.txt

# Usage
1. [local_wordlist] python3 directory_fuzzy.py -u https://example.com -w /path/to/wordlist.txt
2. [remote_wordlist] python3 directory_fuzzy.py -u https://example.com -w https://raw.githubusercontent.com/wordlist.txt
